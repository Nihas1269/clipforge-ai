

\# ClipForge AI — Agent Instructions



\## Project overview



ClipForge AI is a SaaS application for automatically repurposing long-form videos into short-form content.



The intended capabilities include:

\- Video upload and storage

\- Transcription and subtitle generation

\- AI-assisted identification of interesting clips

\- Vertical video reframing

\- Caption customization

\- Video preview and export

\- User dashboard and subscription management



\## Working rules



1\. Read the existing project files before making changes.

2\. Follow the existing architecture and coding conventions.

3\. Do not invent requirements that are not present in the GitHub Issue.

4\. Keep changes focused on the assigned issue.

5\. Do not introduce unnecessary dependencies.

6\. Run relevant tests and report their results.

7\. Explain important changes and any limitations.



\## Git safety



1\. Never work directly on `main`.

2\. Never commit changes to `main`.

3\. Work only on the feature branch assigned to the task.

4\. Never force-push or delete remote branches.

5\. Never merge pull requests.

6\. Never deploy the application.



\## Agent responsibilities



\### Claude

\- Implement assigned GitHub Issues.

\- Make changes only within the assigned feature branch.

\- Run relevant tests.

\- Report files changed and test results.



\### Codex

\- Review changes in read-only mode.

\- Do not modify project files.

\- Do not commit, push, approve, or merge.

\- Report bugs, security concerns, missing tests, and other findings.



\## Human approval



The repository owner makes all final decisions about reviewing and merging pull requests.
